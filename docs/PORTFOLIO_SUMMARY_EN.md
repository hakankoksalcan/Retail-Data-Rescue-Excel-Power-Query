# Portfolio summary

## CV / application description

**Retail Data Rescue — Excel & Power Query**

- Audited 541,909 retail transaction lines, documented missing identifiers, duplicate sensitivity, cancellation handling and special-operation rules, and reconciled every source row and signed amount in an independent reference model.
- Built an Excel dashboard with country/month filters and embedded Power Query source-audit queries; preserved source-row traceability and documented verification coverage.

## Short interview explanation

“I focused on deciding what the data could safely tell us before building charts. I retained duplicates in the main result and quantified an alternative, treated missing customer IDs differently for sales and customer analysis, and separated cancellation records from confirmed physical returns. I checked source and missing-value refreshes in Excel 2021 and used Python for independent reconciliation. The full reporting M model is supplied separately; end-to-end dashboard refresh integration is the next milestone.”
