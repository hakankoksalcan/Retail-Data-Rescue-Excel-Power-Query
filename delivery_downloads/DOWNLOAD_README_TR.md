# Excel kontrol dosyası

Bu dal kontrol dosyasının indirilebilmesi için oluşturulmuştur.

Retail_Data_Rescue_Kontrol.xlsx, Python ile üretilmiş referans çalışma kitabıdır.
Power Query M sorguları henüz gömülü değildir. Gerçek Excel/Power Query
çalışması ve yenileme doğrulaması beklemektedir.

İlk kontrol: masaüstü Excel 2021 ile açın; Dashboard, Settings ve Controls
sayfalarına bakın. Dashboard uygun satış faturası 19.773 olmalıdır.
Veri sekmesinde Veri Al seçeneğinin bulunduğunu kontrol edin.
Yalnızca Tümünü Yenile'ye basmak Power Query doğrulaması değildir.
